25-Day Gym Tracker — install on Android

1. Upload index.html, manifest.webmanifest and sw.js to a GitHub repository.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish. Open the published https://...github.io/... address in Chrome on your Android phone.
5. In Chrome, tap ⋮ > Add to Home screen (or Install app, if shown).
6. Open the new home-screen icon. Your day checkmarks are saved in that browser on that device.

You can also open index.html directly for a basic browser version, but install/offline PWA features require HTTPS hosting such as GitHub Pages.

Privacy: progress is stored locally in your browser using localStorage. Clearing browser site data will clear the tracker.
